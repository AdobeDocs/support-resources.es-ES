# Cómo informar de una vulnerabilidad encontrada por una agencia de seguridad de terceros

Este artículo explica cómo informar de una vulnerabilidad encontrada por una agencia de seguridad de terceros y qué informes de seguridad gestiona Adobe.

## Productos y versiones afectados

Adobe Commerce (todas las versiones)

## Problema

Un comerciante realiza una prueba PEN a través de una agencia de seguridad independiente, y la prueba indica una vulnerabilidad.

## Solución

Para informar de una vulnerabilidad, envíela a [[!DNL Intigriti]](https://app.intigriti.com/programs/adobe/adobepublic/detail). Adobe Commerce no tiene un punto de contacto directo en Intigriti, así que comuníquese con [!DNL Intigriti] directamente para cualquier pregunta.

Adobe revisa y gestiona únicamente los informes generados por Magento Security Scan Tool (MST). Adobe no admite informes de otras herramientas de análisis de seguridad de terceros.
